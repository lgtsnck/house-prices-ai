# Лабораторные работы

Здесь размещаются парные файлы Jupytext (`.py`, формат `py:percent`) и Jupyter Notebook (`.ipynb`).

| № | Запланированное имя (без расширения) | Содержание |
|---|---|---|
| 01 | `01_exploratory_data_analysis` | EDA и постановка задач |
| 02 | `02_data_preprocessing` | Пропуски, выбросы, инженерия признаков |
| 03 | `03_regression_models` | Сравнение моделей регрессии |
| 04 | `04_classification_models` | Сравнение моделей классификации |
| 05 | `05_model_explainability` | Важность признаков и SHAP-анализ |
| 06 | `06_clustering_analysis` | K-means, PCA/t-SNE, DBSCAN при необходимости |

Основную реализацию храним в Python-пакете `house_prices_ai`. Разметка Markdown, вычисленные таблицы и изображения остаются в ноутбуках и используются при оформлении пояснительной записки.

ЛР №1 уже добавлена в двух форматах. Чтобы увидеть реальные результаты, откройте `01_exploratory_data_analysis.ipynb` и выполните все ячейки с локальным `data/raw/train.csv`. Исходные записи не сохраняются в Notebook.
