# Интерактивные исследования

В папке `notebooks/` находятся исследования, объединяющие исполняемый Python-код, таблицы, графики и пояснения к результатам.

Файлы представлены в двух форматах:

- `.ipynb` — Jupyter Notebook для последовательного просмотра и выполнения ячеек;
- `.py` — текстовое представление Jupytext Percent (`# %%`, `# %% [markdown]`), удобное для Git и редактирования в IDE.

Оба представления используют общие функции из пакета `house_prices_ai`, поэтому вычисления не требуется копировать из одного исследования в другое.

## Содержание

| Исследование | Файл | Состояние |
|---|---|---|
| Разведочный анализ характеристик недвижимости | `01_exploratory_data_analysis.ipynb` | Доступно |
| Подготовка и преобразование признаков | `02_data_preprocessing.ipynb` | В разработке |
| Сравнение регрессионных моделей | `03_regression_models.ipynb` | Запланировано |
| Сравнение моделей классификации | `04_classification_models.ipynb` | Запланировано |
| Важность признаков и объяснение прогнозов | `05_model_explainability.ipynb` | Запланировано |
| Кластеризация объектов недвижимости | `06_clustering_analysis.ipynb` | Запланировано |

## Как воспроизвести результаты

Установите зависимости из корневого `requirements.txt`, скачайте `train.csv` в `data/raw/` и откройте `01_exploratory_data_analysis.ipynb` в PyCharm или JupyterLab. Выберите виртуальное окружение проекта и выполните ячейки по порядку.

Исследование содержит вычисленные таблицы, графики и текстовые выводы. Визуализации формируются по локальным данным: без оригинального CSV воспроизвести их нельзя.

При редактировании парных файлов можно использовать Jupytext:

```powershell
jupytext --sync notebooks/01_exploratory_data_analysis.py
```

Синхронизацию выполняйте после сохранения изменений: она предназначена для согласования `.py` и `.ipynb`, а не для одновременного независимого редактирования обеих копий.
