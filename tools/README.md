# Вспомогательные инструменты

В каталоге находятся средства сверки визуальных результатов до и после рефакторинга, а также структурной проверки Notebook. Они не входят в стандартную последовательность обучения моделей.

| Файлы | Назначение |
|---|---|
| `verify_notebooks.py` | Проверка формата и структуры шести Notebook |
| `compare_eda_results.py`, `compare_preprocessing_results.py` | Сравнение рисунков анализа и предобработки |
| `compare_regression_figures.py`, `compare_classification_figures.py` | Сверка диаграмм моделей |
| `compare_explainability_results.py`, `compare_clustering_results.py` | Сравнение интерпретаций и результатов кластеризации |
| `rebuild_regression_figures.py`, `rebuild_classification_figures.py` | Перестроение соответствующих изображений из подготовленных результатов |

Для проверки структуры можно выполнить `python tools/verify_notebooks.py` из корня проекта. Скрипты сравнения требуют заранее подготовленных локальных результатов. Их параметры и ожидаемые пути следует проверять по справке соответствующего скрипта и исходному коду.
