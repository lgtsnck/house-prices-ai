# Вычислительный пакет House Prices AI

Пакет `house_prices_ai` содержит общую расчётную логику для командного интерфейса и Jupyter Notebook. Эксперименты используют одни и те же функции, что уменьшает дублирование кода и расхождение результатов.

| Файл | Назначение |
|---|---|
| `config.py` | Общие пути проекта и параметр случайного состояния |
| `data_loader.py` | Чтение исходного файла и первоначальные проверки |
| `data_dictionary.py` | Словарь характеристик недвижимости |
| `eda.py` | Статистика, анализ пропусков и результаты EDA |
| `preprocessing.py` | Разделение данных, заполнение пропусков, кодирование, инженерия признаков и диагностика |
| `evaluation.py` | Метрики и вспомогательные процедуры оценки моделей |
| `regression.py` | Обучение и сравнение регрессионных моделей |
| `classification.py` | Сравнение классификаторов ценового сегмента |
| `explainability.py` | Feature Importance и SHAP-анализ |
| `clustering.py` | Кластеризация и описание групп недвижимости |
| [`visualization/`](visualization/README.md) | Графики каждого исследовательского направления |
| `__init__.py` | Обозначение Python-пакета |

Для запуска используется корневой `main.py`. Большинство функций формируют локальные артефакты в `outputs/`, а предобработка также сохраняет данные в `data/processed/`. Изменение алгоритмов следует сопровождать соответствующими проверками в каталоге `tests/`.
