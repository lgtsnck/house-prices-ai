# Визуализация результатов

Пакет отделяет построение графиков от расчётных модулей `house_prices_ai`. Такой подход позволяет изменять оформление рисунков без повторного обучения моделей и сохранять единый стиль изображений A4.

| Файл | Назначение |
|---|---|
| `common.py` | Общие функции создания и сохранения изображений |
| `eda.py` | Распределения, диаграммы размаха, корреляции и PCA |
| `preprocessing.py` | Пропуски, важность признаков и проекции подготовленных данных |
| `regression.py` | Метрики, прогнозы, остатки и динамика MLP |
| `classification.py` | Сравнение классификаторов, ROC, Precision–Recall и матрицы ошибок |
| `explainability.py` | Feature Importance и SHAP-графики |
| `clustering.py` | Диагностика и профили кластеров |
| `__init__.py` | Совместимый публичный интерфейс импорта функций визуализации |

Подготовка числовых результатов остаётся в основных исследовательских модулях. Графики генерируются при запуске соответствующего этапа через `main.py` и обычно сохраняются в `outputs/<этап>/figures/`.
