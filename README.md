# House Prices AI

**Курсовой проект по дисциплине «Системы искусственного интеллекта» (уровень «5»).**

Проект посвящён анализу характеристик жилой недвижимости и исследованию методов машинного обучения на наборе данных [House Prices — Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data) (Kaggle / Ames Housing).

## Планируемые задачи

1. **Регрессия:** прогноз `SalePrice` по признакам объекта недвижимости.
2. **Классификация:** определение ценовой категории недвижимости. Порог и баланс классов будут обоснованы после EDA.
3. **Кластеризация:** выделение похожих групп недвижимости без использования целевой переменной в признаках.

Для регрессии и классификации планируется сравнение базовых моделей, случайного леса, XGBoost и нейросети, а также интерпретация лучших моделей с помощью SHAP.

## Требования

- Python 3.13 (проверяемое окружение Windows; в будущем отдельно на macOS Apple Silicon)
- PyCharm или JupyterLab
- Отдельное виртуальное окружение проекта `.venv`

### Быстрый запуск в существующем проекте PyCharm (Windows)

Откройте терминал PyCharm **в корне репозитория**. Если `.venv` уже создан и активен, повторно создавать его не нужно.

```powershell
python -m pip install -r requirements.txt
python main.py info
python main.py plan
python -m unittest discover -s tests -v
```

Для нового клона репозитория на Windows сначала создайте окружение:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

На macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

**Примечание:** на текущем этапе программа поддерживает только команды `info` и `plan`. Команды выполнения лабораторных будут добавляться постепенно вместе с реализацией.

## Получение данных

1. Откройте [страницу соревнования Kaggle](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data).
2. При необходимости войдите в Kaggle и примите условия доступа к данным.
3. Скачайте файлы набора данных; поместите `train.csv` в `data/raw/train.csv`.
4. `test.csv` можно поместить в `data/raw/test.csv`; в нём отсутствует `SalePrice`, поэтому для расчёта метрик обучения/оценки используется размеченный `train.csv` с собственным разделением на обучающую и тестовую выборки.

Исходные CSV и сгенерированные результаты намеренно не хранятся в Git. Расширенное описание — в [`data/README.md`](data/README.md).

## Лабораторные как исполняемые отчёты

Каждая лабораторная будет содержать `.py`-представление в формате Jupytext Percent (`# %%` / `# %% [markdown]`) и парный `.ipynb` с таблицами, кодом и графиками.

Пример синхронизации **после создания первой лабораторной**:

```powershell
jupytext --set-formats ipynb,py:percent notebooks/01_exploratory_data_analysis.ipynb
jupytext --sync notebooks/01_exploratory_data_analysis.py
```

Выполненный `.ipynb` будет удобен преподавателю для просмотра результатов, а `.py` — для просмотра изменений в Git. Для расчётов используются общие функции пакета `house_prices_ai`.

## Воспроизводимость

Для каждой модели фиксируем `random_state`, метод разбиения данных, используемые признаки и метрики. Предобработку будем обучать **только на тренировочной части данных**. При классификации признак `SalePrice` не должен попадать в признаки, поскольку категория цены строится из этой переменной. При кластеризации целевые метки также исключаются из признаков.

Планируемая пояснительная записка будет формироваться по мере выполнения лабораторных, а не отдельно в конце семестра.
