# House Prices AI

**House Prices AI** — проект по исследованию характеристик жилой недвижимости и применению методов машинного обучения для анализа её стоимости. В основе лежит набор данных [House Prices — Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data), содержащий сведения о продажах домов в городе Эймс (штат Айова, США).

Проект объединяет исследование данных, подготовку признаков и эксперименты с моделями в единой модульной структуре. Расчёты выполняются в Python, а результаты можно изучать как через командную строку, так и в интерактивных Jupyter Notebook.

## Задачи проекта

- **Анализ данных.** Изучение распределений, пропущенных значений, нетипичных объектов и взаимосвязей между характеристиками домов.
- **Прогнозирование стоимости.** Построение и сравнение регрессионных моделей для оценки `SalePrice` — цены продажи.
- **Классификация.** Определение ценовой категории объекта по его характеристикам.
- **Группировка недвижимости.** Выявление схожих объектов методами кластеризации.
- **Интерпретация результатов.** Оценка влияния признаков и объяснение прогнозов моделей.

На текущем этапе **реализован разведочный анализ данных (EDA)**: загрузка и проверка набора данных, расчёт описательной статистики, анализ пропусков и корреляций, визуализация распределений, потенциальных выбросов и PCA-проекции. Предобработка, обучение моделей и их интерпретация будут добавляться по мере развития проекта. Подготовленные для этих направлений модули пока не следует считать готовой реализацией.

## Структура проекта

```text
house-prices-ai/
├── main.py                    # Точка входа в приложение
├── house_prices_ai/           # Загрузка, анализ и моделирование
├── notebooks/                 # Интерактивные исследования и пояснения
├── data/
│   ├── raw/                   # Исходный набор данных
│   └── processed/             # Подготовленные наборы данных
├── outputs/                   # Графики, таблицы и результаты запусков
├── docs/                      # Документация и выбранные иллюстрации
├── tests/                     # Автоматические проверки
├── requirements.txt           # Основные Python-зависимости
└── .editorconfig              # Соглашения по оформлению файлов
```

В пакете `house_prices_ai` находятся функции для загрузки и обработки данных. Интерактивные исследования в `notebooks/` используют эти же функции, поэтому расчётная логика не дублируется в отдельных блокнотах.

## Подготовка окружения

Рекомендуется **Python 3.13** и отдельное виртуальное окружение. Команды выполняются из корня репозитория.

### Windows (PowerShell)

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### macOS / Linux

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Команда `python3.13` предполагает, что Python 3.13 установлен и доступен в `PATH`. Проект можно открыть в PyCharm либо работать с ним в JupyterLab.

## Получение данных

Исходные файлы соревнования не включены в репозиторий. Чтобы воспроизвести анализ:

1. Откройте [страницу данных на Kaggle](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data) и примите правила доступа, если потребуется.
2. Скачайте `train.csv` и поместите его в `data/raw/train.csv`.
3. При необходимости сохраните рядом `data_description.txt` — описание исходных характеристик недвижимости.

В `train.csv` содержатся характеристики объектов и фактическая цена `SalePrice`. Отдельный `test.csv` на Kaggle не содержит целевой переменной и не подходит для прямого расчёта метрик. Для оценки моделей размеченные данные будут разделяться на обучающую и проверочную выборки.

Подробнее об устройстве каталога — в [data/README.md](data/README.md).

## Запуск анализа

```powershell
python main.py info
python main.py eda
```

Команда `info` выводит сведения о проекте и ожидаемом пути к данным. Команда `eda` выполняет исследование локального `train.csv` и сохраняет результаты в `outputs/eda/`: статистические таблицы, графики и сводный Markdown-отчёт.

Результаты можно также воспроизвести в [интерактивном блокноте](notebooks/01_exploratory_data_analysis.ipynb). Откройте его в PyCharm или JupyterLab, выберите интерпретатор из `.venv` и выполните все ячейки сверху вниз.

## Проверка и воспроизводимость

```powershell
python -m unittest discover -s tests -q
python -m pip check
```

При проведении экспериментов фиксируются параметры разбиения выборок и генераторов случайных чисел. Преобразования данных, используемые в моделях, должны обучаться только на тренировочной части, чтобы избежать утечки информации в оценку качества. Для классификации и кластеризации цена продажи и производные от неё целевые переменные не включаются в набор входных признаков.

Исходные данные, промежуточные выгрузки и результаты локальных запусков не публикуются в GitHub. Инструкции по интерактивным исследованиям и документации находятся в [notebooks/README.md](notebooks/README.md) и [docs/README.md](docs/README.md).
