# Исходные данные

Основной файл для воспроизведения проекта - `train.csv` из набора [House Prices - Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data). Его необходимо загрузить самостоятельно и поместить в эту папку.

Дополнительно можно разместить `test.csv` без известной цены и `data_description.txt` с описанием полей. Эти файлы не обязательны для основного исследования. Исходные данные не изменяются программой и не включаются в Git. Файл `.gitkeep` обеспечивает наличие папки после клонирования.
