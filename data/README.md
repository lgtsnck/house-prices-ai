# Набор данных

В каталоге хранятся исходные и подготовленные данные для исследования рынка жилой недвижимости на основе [House Prices — Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data) (Ames Housing).

## Исходные файлы

- `raw/train.csv` — характеристики домов с известной ценой продажи `SalePrice`. Это основной источник данных для анализа и построения моделей.
- `raw/test.csv` — дополнительный набор Kaggle без `SalePrice`, не используется для прямого расчёта метрик качества.
- `raw/data_description.txt` — описание характеристик и их значений, если файл загружен с Kaggle.

Для воспроизведения исследования достаточно скачать `train.csv`, принять условия доступа к соревнованию и разместить файл в `data/raw/`. Исходный CSV при анализе не перезаписывается.

## Подготовленные данные

Папка `processed/` предназначена для промежуточных наборов признаков и результатов преобразований. Предобработка должна выполняться с учётом разбиения на обучающую и тестовую выборки, чтобы статистики тестовых объектов не влияли на обучение.

Некоторые обозначения отсутствующих значений имеют предметный смысл: например, отсутствие гаража или бассейна. Прежде чем заполнять пропуски, необходимо различать такие случаи и действительно неизвестные значения. Строка `None` в отдельных категориальных признаках также может быть значимой категорией.

## Публикация

Исходные и подготовленные таблицы исключены из Git и хранятся локально. Репозиторий содержит код для воспроизведения результатов, а не копию конкурсного набора данных. При скачивании и использовании файлов необходимо соблюдать правила Kaggle.
