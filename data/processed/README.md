# Подготовленные данные

Файлы в этом каталоге создаются командой `python main.py preprocessing`. Они содержат отдельные обучающие и тестовые матрицы признаков и целевые переменные для регрессии и классификации.

Основные выгрузки представлены парами `X_train_reg.csv` и `X_test_reg.csv`, `y_train_reg.csv` и `y_test_reg.csv`, а также аналогичными файлами с суффиксом `clf`. Списки идентификаторов объектов сохраняются в `train_ids.csv` и `test_ids.csv`.

Каталог не предназначен для ручного редактирования исходных записей. Файлы исключены из Git и пересоздаются при запуске обработки данных. Описание методов и диагностические таблицы находятся в `outputs/preprocessing/`.
