# Иллюстрации для документации

В этот каталог помещаются только отобранные изображения, которые нужны для текстовой части проекта и дальнейшего оформления пояснительной записки. Исходные рисунки создаются программно и сохраняются в локальных `outputs/<этап>/figures/`.

При переносе изображений сохраняются понятные имена файлов, номер рисунка, читаемые подписи и соотношение сторон, подходящее для книжного листа A4. Содержательные описания и выводы размещаются рядом с рисунками в Notebook либо в тексте исследования. Автоматически копировать сюда все результаты не требуется.

Пока папка может содержать только этот README. Отсутствие изображений здесь не означает отсутствие результатов в Notebook.
