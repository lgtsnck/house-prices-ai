# Иллюстрации

Здесь размещаются отобранные изображения, предназначенные для включения в документацию проекта: графики распределений, схемы обработки данных и визуализации результатов моделирования.

Изображения должны строиться программно по результатам расчётов. Для печатных материалов используются читаемые подписи и книжный формат A4. Развёрнутые объяснения и выводы приводятся в тексте документации, а не в самом изображении.

Полный набор автоматически созданных графиков хранится локально в `outputs/`. В эту папку включаются только выбранные иллюстрации, необходимые для документации.
