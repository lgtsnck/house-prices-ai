# Иллюстрации для документации

Каталог содержит изображения, встроенные в единое исследование `docs/README.md`. Сохранённые графики извлекаются из результатов выполнения Jupyter Notebook без повторного запуска вычислений. Изображения находятся в подкаталоге `notebook-figures/` и используются через относительные пути Markdown.

Имена изображений содержат номер раздела, номер ячейки и порядковый номер результата. Это позволяет воспроизвести структуру документа без ручного переименования рисунков. Подписи и пояснения сохраняются рядом с иллюстрациями в тексте исследования.

Графики, сформированные при новых запусках проекта, первоначально сохраняются в локальном каталоге `outputs/`. При обновлении Notebook документ собирается повторно, чтобы изображения и текст соответствовали зафиксированным результатам. Интерактивные JavaScript-визуализации в GitHub Markdown полноценно не воспроизводятся.
